创建营销活动
##################

.. vale on

创建营销活动是营销自动化流程的核心部分。当您创建新的营销活动时，需要执行基本的管理任务，例如为营销活动命名、编写描述、分配类别以及定义激活信息。

任何营销自动化营销活动的核心都是营销活动构建器。它允许您指定联系人如何进入营销活动，以及进入工作流程后每个环节将发生什么。

在完成基础设置后，营销活动构建器将使用条件、决策和操作来处理构建营销活动工作流程的细节。

前提条件
*************

在开始创建营销活动之前，必须确保已完成以下设置：

#. 创建联系人分组或表单来初始化您的营销活动。如果已有现成的分组或表单可供使用，请确保它们是最新的。

#. 创建联系人档案所需的任何自定义字段。
#. 设置并配置您计划在营销活动中使用的任何集成。
#. 设置适当的渠道（如短信、电子邮件、焦点项目）以便与联系人沟通。
#. 创建资源、落地页或其他您希望用于营销活动的组件。如果使用资源，请确保在创建营销活动之前已上传。

虽然您可以在创建营销活动的过程中设置渠道和创建组件，但提前准备好这些内容将使营销活动构建过程更快速、更高效。

.. vale off

创建您的第一个营销活动
**************************

.. vale on

在满足前提条件后，您就可以开始创建第一个营销活动了。

要开始创建营销活动，请执行以下步骤：

.. vale off

#. 启动您的 Mautic 实例。
#. 点击左侧导航菜单中的 **营销活动**。此时将显示营销活动页面。
#. 点击营销活动页面上的 **新建**。此时将出现新建营销活动向导，如下图所示。新建营销活动界面的截图

   .. image:: images/new-campaign.png
      :width: 600
      :alt: 新建营销活动界面的截图

#. 为您的营销活动输入名称和简要描述。
#. 可选地，您可以设置以下属性：

   *  **类别** - 选择要分配给营销活动的类别。类别有助于您组织营销活动。要了解有关创建和管理类别的更多信息，请参阅 :doc:`/categories/categories-overview`。
   *  **允许联系人重新启动营销活动** - 控制已退出营销活动的联系人是否可以重新进入并再次经历工作流程。对于重复性消息（如生日或订阅续期）或事务性操作（如活动通知），请启用此选项。禁用时，即使联系人之后再次符合原始分组或表单的条件，已退出的联系人也不能重新启动。
   *  **营销活动重新激活行为** - 配置当您重新激活已停用的营销活动时，具有相对延迟的预定事件应如何表现。您可以为此特定营销活动覆盖全局默认设置。有关可用选项的更多信息，请参阅 :ref:`营销活动重新激活行为` 部分。
   *  **启用** - 点击切换开关以打开或关闭营销活动。请确保在您真正准备上线之前不要激活营销活动。您还可以通过选择时间和日期来安排将来某个时间激活或停用营销活动。

#. 点击 **启动营销活动构建器** 开始构建您的营销活动，并至少添加一个事件。有关如何使用营销活动构建器的信息，请参阅 :doc:`/campaigns/campaign_builder`。

#. 为营销活动添加事件后，关闭营销活动构建器并点击 **保存并关闭** 以保存更改。

.. vale on

批量添加或移除联系人
*******************************

创建营销活动后，您可以使用以下命令为营销活动批量添加或移除联系人：

.. code-block:: shell

   php /path/to/mautic/bin/console mautic:campaigns:update

有关更多详细信息，请参阅 :doc:`/configuration/cron_jobs` 文档。

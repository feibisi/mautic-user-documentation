Clearbit
########

此插件可以：

* 通过 API 从 Clearbit 拉取联系人和公司的数据到 Mautic 中。

Clearbit 插件要求
****************************

* Mautic 需安装在可公开访问的 URL 上。由于 Clearbit 需要向 Mautic 发送回调，此插件无法在 localhost 上运行。

* 获取 Clearbit API 密钥

角色
#####

您可以通过为用户创建账户并将其与角色关联来控制对 Mautic 实例的访问。

:doc:`用户</users_roles/managing_users>` 是个人用来访问 Mautic 的账户，而 :ref:`角色<roles>` 则允许或拒绝对 Mautic 内各种功能的访问。

Mautic 使用角色来控制用户可以访问哪些资源和操作。当团队成员有不同的职责时，您可能不希望某些团队成员在 Mautic 的某些部分工作。

默认情况下，Mautic 创建的新用户具有完整系统访问权限的管理员角色。您可以在手动创建用户时更改此设置，或在通过 API 导入用户时选择不同的角色。

.. vale off

创建新角色
*******************

.. vale on

完整系统访问权限
==================

如果您将 **完整系统访问权限** 开关选择为 **是**，您将创建一个管理员账户，该账户对您的 Mautic 实例具有最高级别的访问权限。

.. image:: images/full-access-roles.png
  :alt: Screenshot showing Mautic Roles

1. 导航至 **设置** > **角色**。

2. 点击右上角的 **+新建**。

3. 在 **详情** 选项卡中，添加 **标题** 和 **描述**。

4. 在 **完整系统访问权限** 开关上选择 **是**。

5. 点击 **保存并关闭**

限制此类账户的数量，并确保其凭据安全。

如果您选择此选项，您将无法在 **权限** 下配置任何内容，因为默认情况下，此账户拥有对所有内容的完整访问权限。

设置细粒度权限
============================

Mautic 允许您为 Mautic 的每个 bundle（或部分）创建具有细粒度权限的角色。

要配置角色，请将 **完整系统访问权限** 开关保持为 **否**，然后点击 **权限** 选项卡开始构建角色。

1. 导航至 **设置** > **角色**。

2. 点击右上角的 **+新建**。

3. 在 **详情** 选项卡中，添加 **标题** 和 **描述**。

4. 点击权限选项卡。用户权限列表会显示出来。

.. image:: images/mautic-roles.png
  :width: 800
  :alt: Screenshot showing Mautic Roles

5. 大多数权限分类都有 **查看**、**编辑**、**创建**、**删除** 和 **激活** 选项。为此角色勾选相应的权限复选框。要选中所有复选框并授予用户所有权限，请选择 **完整** 选项。

权限选项说明
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

选择权限时有以下几个选项：

* **查看** — 这允许拥有此角色的用户查看 Mautic 的这一部分

* **编辑** — 这允许拥有此角色的用户对 Mautic 的这一部分进行更改

* **创建** — 这允许拥有此角色的用户在 Mautic 的这一部分中创建新资源

* **删除** — 这允许拥有此角色的用户删除 Mautic 这一部分中的资源

* **激活** — 这允许拥有此角色的用户通过激活来使 Mautic 这一部分中的资源变为可用

* **完整** — 这允许拥有此角色的用户拥有所有权限。

有与用户自己创建的资源以及他人创建的资源相关的权限级别：

* **自己的** — 这允许拥有此角色的用户 ``查看/编辑/删除/激活`` 自己在 Mautic 这一部分中创建的资源，但不能操作他人创建的资源

* **他人的** — 这允许拥有此角色的用户 ``查看/编辑/删除/激活`` 自己在 Mautic 这一部分中创建的资源，以及他人创建的资源

有与能够管理资源相关的权限级别：

* **管理** — 这允许拥有此角色的用户管理 Mautic 这一领域中的资源，例如管理自定义字段或插件。

有与用户部分中可编辑字段相关的权限级别：

* **指定字段** — 允许或拒绝拥有此角色的用户编辑用户部分中的指定字段，例如姓名、用户名、邮件、职位。

* **全部** — 这允许拥有此角色的用户编辑与用户部分相关的所有字段

从 Mautic 5.1 起，新增了一个与允许 Mautic 用户导出信息相关的权限。您可以在联系人、表单和报告权限中设置此权限。如果未设置此权限，用户将不会看到导出信息的选项，也无法从 Mautic 中导出信息——例如联系人列表、表单提交数据和报告数据。

.. note::

  用户权限会限制他们对仪表盘小组件的查看，导致他们只能看到有权查看的项目或功能 bundle 的小组件。

  例如，如果用户的角色没有资源权限，他们就无法在仪表盘上创建或查看资源数据的小组件。

您也可以通过 :xref:`Roles using the API`。

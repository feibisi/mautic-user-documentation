标签
####

.. vale on

标签是灵活的标记，您可以随时为联系人添加或移除。与基于筛选条件对联系人进行分组的"分组"不同，标签允许您手动对联系人进行分类，以便快速识别、筛选和触发营销活动操作。

.. vale off

管理标签
*********

.. vale on

.. vale off

创建标签
=========

.. vale on

标签无需预先创建。您可以在为联系人应用标签时直接创建新标签——在任何标签字段中输入新标签名称，Mautic 便会自动创建该标签。

要查看现有标签，请导航至联系人的记录并查看标签字段，或在搜索联系人时使用标签筛选器。

.. vale off

为联系人添加标签
=================

.. vale on

手动分配
---------

.. vale off

#. 导航至联系人的记录。
#. 点击**编辑**以打开联系人编辑表单。
#. 在**标签**字段中，开始输入以搜索现有标签或输入新标签名称。
#. 按 Enter 键或从下拉菜单中选择以应用标签。
#. 点击**保存**以保存更改。

.. vale on

批量更新
---------

#. 导航至**联系人**部分。
#. 使用筛选器找到需要更新的联系人。
#. 选中目标联系人旁边的复选框。
#. 点击列顶部的绿色箭头。
#. 从下拉菜单中选择**更改标签**。
#. 选择要添加或移除的标签。
#. 点击**保存**。

使用跟踪脚本
------------

您也可以使用跟踪脚本或跟踪像素为联系人添加或移除标签。更多信息，请参阅 :ref:`联系人跟踪` 部分。

在营销活动中使用标签
*********************

.. vale on

.. vale off

修改联系人标签操作
===================

.. vale on

使用**修改联系人标签**操作，在为营销活动推进过程中的联系人添加或移除标签。

#. 在营销活动构建器中，点击事件下方的连接器。
#. 选择**操作**。
#. 选择**修改联系人标签**。
#. 选择要添加或移除的标签。
#. 点击**添加**以保存操作。

该操作适用于标记那些已到达特定阶段、完成特定操作或需要跟进的联系人。

.. vale off

联系人标签条件
===============

.. vale on

使用**联系人标签**条件，根据联系人是否拥有特定标签来创建不同的营销活动分支路径。

#. 在营销活动构建器中，点击事件下方的连接器。
#. 选择**条件**。
#. 选择**联系人标签**。
#. 配置需要匹配的标签。
#. 点击**添加**以保存条件。

拥有匹配标签的联系人将遵循**是**路径，其他联系人则遵循**否**路径。

.. vale off

在表单中使用标签
*****************

.. vale on

当联系人提交表单时，您可以自动添加或移除标签。

#. 导航至**组件** > **表单**并编辑表单。
#. 在表单构建器中，转到**操作**选项卡。
#. 点击**添加新操作**并选择**修改联系人标签**。
#. 选择在表单提交时要添加或移除的标签。
#. 点击**添加**以保存操作。

这有助于根据联系人完成的表单来标记他们，例如将某人标记为对特定产品感兴趣。

.. vale off

在分组中使用标签
*****************

.. vale on

您可以在构建分组时将标签用作筛选条件：

#. 导航至**分组**，创建或编辑一个分组。
#. 转到**筛选器**选项卡。
#. 添加筛选条件，并从联系人字段选项中选择**标签**。
#. 选择运算符。例如，**包含**、**排除**、**为空**或**不为空**。
#. 选择用于筛选的标签。
#. 点击**保存**以应用筛选条件。

这样可以创建包含已应用或未应用特定标签的联系人的分组。

.. vale off

按标签搜索联系人
******************

.. vale on

您可以使用搜索栏搜索带有特定标签的联系人：

* 要查找带有特定标签的联系人，请使用 ``tag:标签名``
* 要查找不带有特定标签的联系人，请使用 ``!tag:标签名``

将 ``标签名`` 替换为标签的实际名称。如果标签名称包含空格，请用引号将其括起来，例如 ``tag:"标签名称"``。

最佳实践
**********

* **使用一致的命名规范** - 建立命名规则以避免重复，例如为类似用途使用'Webinar'和'webinar-attendee'。
* **记录标签分类体系** - 记录每个标签的含义及使用场景。
* **避免过度打标签** - 过多的标签可能难以管理。请考虑使用分组或自定义字段是否更合适。
* **定期审查标签** - 定期审计标签，移除已过时或未使用的标签。
* **与分组结合使用** - 使用标签进行快速手动标记，使用分组进行基于筛选条件的动态分组。

管理用户
##############

.. vale on

管理员可以通过点击屏幕右上角的设置齿轮图标，在 Mautic 中管理具有适当权限的用户。

创建用户时，填写所有必填字段，根据需要添加签名，并为其分配用户名和密码。对于有权限访问您 Mautic 实例的用户，请始终使用安全密码。

.. image:: images/mautic-users.png
  :alt: Screenshot showing Mautic Users

您可以手动或通过 API 在 Mautic 中设置新用户。

要手动设置用户：

1. 导航至 **设置** > **用户**。

2. 点击右上角的 **+新建**。

3. 为用户填写相应的字段：

   * **名字** 和 **姓氏** — 您用户的名字和姓氏。

   * **角色** 根据您授予的权限进行分配。

   * **签名** 仅在您使用 Mautic 中的"邮件发送者即所有者"功能时才需要。

   * **职位 - 可选** — 您用户的职位名称。

   * **用户名、邮件、密码** 是登录凭据。如果用户忘记密码，可以使用"忘记密码"链接，但您可以在此处手动更改他们的密码。

.. note::

    密码长度必须至少为六个字符。请确保使用大小写字母、特殊字符和数字的组合。

* **时区** — 设置用户的时区，或使用默认值。添加用户的时区使其能够考虑邮件调度和其他功能的时区差异。

* **语言** — 为每位用户选择语言，以改善他们在 Mautic 中的使用体验。

创建用户后，请告知他们凭据。Mautic 不会发送邮件通知用户登录信息。需要手动告知他们。

营销活动概述
==================

营销活动是一种营销行为，它将组件与渠道协调一致，通过战略性定时的方式发布内容，以达成特定的业务目标。在添加联系人并设置所需渠道后，您可以创建营销活动来与联系人建立有意义的互动关系。

营销活动可用于联系人管理、营销运营和销售工作流。一个营销活动可以向分组中的所有联系人，或您指定的部分联系人发送个性化消息。您可以设置营销活动的时间安排，使消息发送一次或按固定间隔重复发送，例如每周一次。

营销活动工作流的主要优势之一是能够预先定义这些流程，并使其自动响应联系人及其时间线。这种自动化减少了手动处理联系人活动所需的时间，并提高了联系人培育的可靠性。

营销活动类型
--------------

营销活动大致可分为三种类型：

.. vale off

定时型营销活动
~~~~~~~~~~~~~~~~~~~~~

.. vale on

定时型营销活动是以特定定时事件为核心的营销活动类型。这些事件可以是任何内容，但通常是电子邮件。例如，您可以选择在预设天数延迟后，或在未来的特定日期触发此类电子邮件事件。

.. vale off

联系人驱动型营销活动
~~~~~~~~~~~~~~~~~~~~~~~~

.. vale on

联系人驱动型营销活动可根据与特定联系人的交互行为触发事件。这些交互可能源于联系人访问某个网页或着陆页、打开电子邮件、在网站上停留指定时长或任何其他活动。此类营销活动通常可通过立即或在未来特定时间向联系人发送电子邮件来响应这些行为。

.. vale off

混合型营销活动
~~~~~~~~~~~~~~~

.. vale on

Mautic 允许您创建同时包含定时型营销活动和联系人驱动操作的营销活动。这种强大的混合营销活动策略可依据特定日期或特定时间范围，以及联系人直接采取的行动来驱动操作。

.. note::
    营销活动可以触发多种操作。前述营销活动类型中提到的电子邮件操作仅是一个示例。营销活动可以触发的其他操作包括自动分配至新分组、分配新的积分值，或推送至集成系统、CRM 或其他系统。

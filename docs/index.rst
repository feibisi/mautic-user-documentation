欢迎来到 Mautic 文档
===================================

**Mautic** 是一个开源营销自动化平台，为您提供最深入的受众洞察，从而使您能够建立更有意义的客户连接。

要开始使用 Mautic，请遵循 :doc:`入门指南</getting_started/how_to_install_mautic>`。
关于后续步骤，您可以学习 :doc:`如何更新 Mautic</getting_started/how_to_update_mautic>`。

有不同类型的文档可帮助您浏览 Mautic。

:xref:`End User Documentation` - 详细描述 Mautic 的每个方面并解释如何使用。

:xref:`Developer Documentation` - 描述有关 Mautic API、Webhooks、主题和插件开发的详细信息。

:xref:`Knowledgebase` - 提供教程、常见问题和操作指南文章的数据库。

:xref:`Community Handbook` - 描述如何参与并为 Mautic 文档开发做出贡献。

.. note::

   本文档项目正在积极开发中。

积分故障排除
######################

页面访问未被识别
**************************

要解决此问题，请尝试以下选项之一：

1. 确保您未在登录 Mautic 的状态下进行测试。Mautic 会忽略 Mautic 管理员的访问活动。因此，建议您使用匿名会话、隐私窗口、其他浏览器，或退出 Mautic 登录。

2. 积分操作的跟踪当前每个联系人仅执行一次。这意味着后续访问如果已经触发过一次操作，则不会再重新触发。

3. 确保定义的 URL 与访问的 URL 完全匹配，或使用通配符。URL 可以包含协议、主机/域名、路径、查询参数和/或片段。

例如，如果您定义的 URL 是 ``https://example.com``，而页面访问记录为 ``https://example.com/index.php?foo=bar``，则该积分操作不会被识别。但是，如果您使用 ``https://example.com*`` 作为 URL，则会匹配规则并触发操作。

焦点项目
###########

焦点项目允许您通过横条、模态窗口、通知、弹窗和灯箱来吸引网站上的用户。您可以在不同时间以不同操作（例如退出意图）来触发焦点项目。

您可以在渠道菜单下找到焦点项目。

焦点项目设置
*******************
有多种不同类型的焦点项目，以及多种配置方式来帮助您实现战略营销目标。

焦点项目类型
===================

您可以在 Mautic 中创建三种不同类型的焦点项目。这些让您能够通过焦点项目实现不同的营销目标。请根据您的需求选择适当的选项。

  .. image:: images/focus_items/focus_item_types.png
    :width: 400
    :alt: Screenshot showing the types of Focus Items.

- **收集数据** — 此选项会在焦点项目中展示一个表单——该表单必须已存在。这让您能够收集更多关于网站访客的信息。当有表单提交时，Mautic 将此类型焦点项目视为一次成功转化。此选项非常适合收集简单信息——例如新闻通讯注册表单。
- **显示通知** — 此选项会向您的访客展示一条消息。此类型焦点项目没有检测转化的选项。此选项非常适合公告和重要消息。
- **突出链接** — 此选项允许您引导访客访问特定链接，该链接可能是您网站上的资源、Mautic 落地页或任何其他基于网络的资源。对于此焦点项目，Mautic 将链接点击视为一次成功转化。此选项非常适合用于落地页来突出促销或销售活动——它会显示一个按钮，点击后将访客引导到指定的链接。

交互选项
==================

每种焦点项目类型都有配置设置，用于控制焦点项目的触发方式以及它们与访客的交互方式。

  .. image:: images/focus_items/focus_item_engagement.png
    :width: 400
    :alt: Screenshot showing the engagement settings for Focus Items.

- **动画** — 设置为"是"时，会为焦点项目应用滑入动画。设置为"否"时，项目出现时没有任何滑动效果。
- **何时触发** — 此设置控制焦点项目的显示时机。有以下几种选项：
   - **到达时** — 访客一进入页面就显示
   - **稍微向下滚动后** — 稍等片刻，直到访客开始向下滚动页面
   - **滚动到中间后** — 等到访客滚动到页面中间
   - **滚动到底部后** — 等到访客一直滚动到页面底部
   - **访客意图离开** — 如果访客的光标移动到地址栏上方，或从页面移动到标签页——例如要关闭标签页或打开新标签页
- **触发前超时** — 此选项允许您设置在达到"何时触发"所选条件后延迟的秒数。例如，如果设置为"到达时"且"触发前超时"为 2 秒，则焦点项目会在访客到达页面 *2 秒后* 出现。
- **触发频率** — 此选项允许您控制焦点项目向访客显示的频率。可用选项包括：
   - **每个页面** — 在访客与您网站交互的每个页面上显示
   - **每次会话一次** — 访客每次访问您网站时显示一次
   - **每 2 分钟** — 访客在您网站上每两分钟显示一次
   - **每 15 分钟** — 访客在您网站上每 15 分钟显示一次
   - **每小时一次** — 访客在您网站上每小时显示一次
   - **每天一次** — 访客在您网站上每天显示一次
- **转化后停止触发** — 此选项仅适用于跟踪转化的类型（收集数据和突出链接）。如果设置为"是"，一旦访客提交了表单（收集数据类型）或点击了链接（突出链接类型），焦点项目将不再显示。
- **关闭焦点后停止触发** — 此选项适用于焦点项目并使用 Cookie。如果设置为"是"，访客与焦点项目交互后，焦点项目将不再显示，直到他们清除 Cookie。

样式
======

创建焦点项目时有四种样式可供选择。每种样式都有与其提供的布局相关的不同配置选项。

  .. image:: images/focus_items/focus_item_styles.png
    :width: 400
    :alt: Screenshot showing the styles for Focus Items.

横条
~~~
横条样式在页面顶部或底部创建一条线，包含您的焦点项目内容。

- **允许隐藏** — 设置为"是"时，网站访客会看到一个小箭头来隐藏横条。箭头显示在横条的右侧。点击后，横条会收缩以隐藏内容，但箭头仍然可见，访客可以通过单击重新展开横条。如果设置为"否"，访客无法隐藏横条。
- **下推页面** — 此选项设置为"是"时，横条会将页面内容向上或向下推到横条下方。如果设置为"否"，横条会根据位置设置覆盖页面顶部或底部的内容。
- **固定位置** — 如果设置为"是"，即使访客滚动页面，横条也会保持在固定位置。如果设置为"否"，横条不会固定，会随着访客滚动页面而消失，并在反向滚动时重新出现。
- **位置** — 此选项允许您将横条显示在页面的顶部或底部。
- **大小** — 此选项允许您指定横条的厚度和字体大小。选项包括：
    - **大** — 50px 高度和 17pt 字体
    - **常规** — 30px 高度和 14pt 字体

模态窗口
~~~~~
模态窗口样式可能是最流行的样式，通常被称为弹窗或灯箱。

模态窗口是水平居中对齐在页面上的小方框。当焦点项目处于活动状态时，弹窗后面的内容会变暗，这有助于将注意力——焦点——吸引到弹窗上。

- **位置** — 此选项允许您选择模态窗口是显示在页面的顶部、中间还是底部。

通知
~~~~~~~~~~~~

通知样式是一个出现的小方框，有时被称为弹窗。与模态窗口样式不同，弹窗显示在页面的四个角之一，并且通知下方的主要内容不会在弹窗后面变暗。

访客可以通过点击通知右上角的 *X* 按钮来关闭此类型的焦点项目。

- **位置** — 此选项允许您选择显示通知的角落。

全页面
~~~~~~~~~

全页面焦点项目会完全占据整个页面，隐藏页面内容，直到访客点击焦点项目右上角的 *X* 按钮。

此样式焦点项目没有额外的配置选项。

颜色
======

默认情况下，Mautic 会从快照中提取顶部颜色。目前支持四种颜色。您可以使用颜色选择器或输入十六进制代码来自定义颜色。

- **主色**
  - 对于横条样式，主色是横条的背景色
  - 对于模态窗口、通知和全页面样式，主色是焦点项目周围的轮廓线，顶部的线条比其他三面更粗。
- **文字颜色** — 在焦点项目编辑器的"内容"部分中输入的标题文字颜色
- **按钮颜色** — 收集数据和突出链接类焦点项目的按钮背景色。此选项不适用于"显示通知"类焦点项目。
- **按钮文字颜色** — 收集数据和突出链接类焦点项目的按钮文字颜色。此选项不适用于"显示通知"类焦点项目。

内容
=======
自定义焦点项目时有三种编辑模式可供选择。

  .. image:: images/focus_items/focus_item_content.png
    :width: 400
    :alt: Screenshot showing the content options for creating Focus Items.

基础
~~~~~
此编辑器模式提供了简化的体验，包含少量字段——取决于焦点项目类型——内容在创建时会自动渲染到焦点项目上。

- **标题** — 这是焦点项目上使用的主要文字。目的是吸引访客的兴趣和注意力。
- **标语** — 此选项仅适用于"突出链接"类焦点项目。它允许您提供第二行文字，为访客点击链接增加更多动力。此字段为可选。
- **字体** — 此选项允许您从可用字体中选择用于焦点项目的字体。字体列表不可自定义。
- **选择要插入的表单** — 此选项仅适用于"收集数据"类焦点项目。它允许您选择一个现有的 Mautic 表单与焦点项目一起使用。出于样式和格式原因，您可能需要专门为焦点项目创建一个表单，并在表单字段的"属性"选项卡中添加样式属性。
- **链接文字** — 此选项仅适用于"突出链接"类焦点项目。它允许您指定焦点项目按钮上使用的文字。
- **链接 URL** — 此选项仅适用于"突出链接"类焦点项目。它允许您指定要通过焦点项目将访客引导到的 URL。
- **在新窗口中打开** — 此选项仅适用于"突出链接"类焦点项目。如果设置为"是"，这将确保链接在新窗口中打开。如果设置为"否"，链接在当前标签页中打开。

编辑器
~~~~~~
这允许用户使用 Mautic 中可用的全局编辑器来编辑内容。

HTML
~~~~
这允许用户将 HTML 输入到空白字段中，以创建完全自定义的焦点项目。

.. note::
    如果您决定切换编辑样式，请确保清除之前样式的数据，否则 Mautic 可能无法显示最终预期的内容。


创建焦点项目
*********************

要创建新的焦点项目，请前往 渠道 > 焦点项目 并点击新建按钮。

.. warning::
    某些网站不允许显示预览。要使预览正常工作，网站必须使用 SSL 证书，并且不得使用 ``x-frame-options: SAMEORIGIN`` 头部阻止 iframe 预览。如果不满足这些条件，焦点项目构建器中将显示错误。

创建新焦点项目时，您可以设置以下字段：

**名称** — 用于在内部标识焦点项目的名称

**网站** — 您想在构建焦点项目时用于预览的网站——请参见前面的注释，某些网站不允许此功能。如果这有问题，请将 URL 字段留空。

**分类** — 分配一个分类来帮助您组织焦点项目。

**活动** — 焦点项目是否可用（活动）或不可用（非活动）。

.. vale off

**激活时间（日期/时间）** — 这允许您定义此短信可发送给联系人的日期和时间

**停用时间（日期/时间）** — 这允许您定义此短信停止可发送给联系人的日期和时间。

.. vale on

**Google Analytics UTM 标签** — Mautic 支持在邮件、焦点项目和落地页中进行 UTM 标记。任何已填充值的 UTM 标签都会自动附加到焦点项目中使用的任何链接的末尾。有关更多信息，请参见 :doc:`/channels/utm_tags`。

  .. image:: images/focus_items/focus_item_create.png
    :width: 400
    :alt: Screenshot showing the creation of a Focus Item.

.. vale off

使用焦点项目构建器
============================

.. vale on

在您指定了焦点项目的基本信息后，点击右上角的构建器选项。如果您在详情页的"网站"字段中指定了 URL，系统会显示预览。如果您看不到预览，则该网站可能阻止了 iframe 预览。因此，您可能需要将焦点项目添加到一个没有这些安全限制的开发或测试环境中——如果可用的话——来查看预览。

.. note::
    在您从焦点项目构建器的选项中选择样式之前，网站预览不会出现。

  .. image:: images/focus_items/focus_item_builder.png
    :width: 400
    :alt: Screenshot showing the Focus Item Builder

您可以使用侧边栏菜单根据自己的喜好配置焦点项目。左侧的预览区域让您可以看到它在您网站上的显示效果。您还可以使用右上角的手机图标切换到响应式视图。这对于确保您不会在移动设备上阻挡用户体验的关键元素非常重要。

  .. image:: images/focus_items/focus_item_builder_responsive.png
    :width: 400
    :alt: Screenshot showing the Focus Item Builder in responsive mode.

使用焦点项目
*****************

创建好焦点项目后，您就可以将其激活到您的网站上。如果您还没有完全准备好让焦点项目上线，但需要在网站上设置它，请将焦点项目设置为非活动状态。

部署到网站
======================

保存焦点项目时，Mautic 会在焦点项目概览页面中以绿色方框显示用于在网站上显示它所需要嵌入的代码片段。

  .. image:: images/focus_items/focus_item_embed.png
    :width: 400
    :alt: Screenshot showing the Focus Item code to embed within a website.

.. note::
    您可能需要网站开发团队的协助来在您的网站上实现焦点项目跟踪代码。

    您还必须确保已在 Mautic 实例的 CORS 设置中指定了您希望使用焦点项目的网站域名，否则它将不会出现。要验证这一点，请前往 设置 > 配置 > 系统设置 > CORS 设置，将"限制域名"设置为"是"。确保在相关字段中指定您的域名。或者（但不推荐，因为这会允许其他网站显示您的焦点项目），将"限制域名"设置为"否"，不指定您的域名。

.. vale off

通过营销活动部署
============================

.. vale on

可以将焦点项目作为营销活动工作流的一部分来触发显示。这不需要您将焦点项目代码粘贴到网站上，因为它是通过现有的 Mautic 跟踪代码来传递的。

在营销活动中，添加一个"访问页面"的决策，然后选择"显示焦点项目"操作。请注意，您必须先有"访问页面"才能触发焦点项目。

.. warning::
    有时营销活动操作可能不太可靠，这取决于您的营销活动步骤，因此在大多数情况下建议使用直接嵌入方法。

衡量成功
*****************

使用"突出链接"类型时，Mautic 会在焦点项目概览页面上显示该链接，您可以在其中查看独立点击次数。

如果您在部署后更改焦点项目中的链接，Mautic 会在概览中列出所有链接。

此外，Mautic 会对焦点项目中的表单提交和链接点击应用 UTM 标签。如果您使用焦点项目来提交表单，建议您在表单上设置一个提交操作来记录 UTM 标签。
